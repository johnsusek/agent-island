## Rules I've learned
- Fish: one fish order yields ~2 fish; runs drop the bay 3-8 points.
- Fish breed fastest at half capacity (20/40), never from empty. Village rule: `fish` only when bay is above 30 (or basket full).
- Starving exception (council notice t344): `fish-starving` only when satiation is 10 or less, basket empty, and bay above 20. One fish each.
- Hunger: "very hungry"/"starving" every ~30-40 ticks; one eaten fish clears it. Eat order cancels if a prior order is still running - wait_for_change first.
- Speak limit 160 chars; hears only within a few paces.

## Lessons
- Keep a spare fish when fishing; give it to whoever is starving, not just whoever asks first.
- Ask for a starving exception early, before someone is starving with an empty pack (I proposed it at t329 and the council agreed).
- Dying of hunger is the real risk once the bay is low.
