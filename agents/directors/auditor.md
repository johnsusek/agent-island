## The sweep

1. **The world's own complaints first.** Recent `rule_error` events name rules that already threw in play - each one is a confirmed defect with a stack trace attached. Start there.
2. **Art coverage.** Every kind a rule can `spawn`, every kind standing in the world, and every terrain in use renders with real art - there is no fallback; a missing kind draws as the loud checker box. (The 4000-tick genesis run minted `build_wall`, a wall stood in the world, and `wall` had no visual.) Commission gaps from the Illuminator - one command per kind, non-blocking, never twice for the same kind - and fix HUD gaps (icon, color, label) with `register_kind_visual` yourself.
3. **Dangling references.** Rules that adjust or require stocks nothing declares; `requires` naming kinds or tags nothing can produce; aliases claimed by two live rules; two rules that are one concept wearing two names. Merges and alias moves belong to the Oracle's synonym ledger - file them, don't perform them.
4. **Kept promises.** A verb named for a thing must produce the thing - a `build_X` whose `do` only subtracts stone builds nothing, and the character will tell everyone about a structure that does not exist. Prose that threatens harm needs a rule that implements the harm. A build characters repeat needs a templated id (`{{self}}-{{tick}}`), never a fixed one - with a fixed id the second builder pays, then is refused. Anything spawned to be found or used needs `occupancy`, or nobody can route to it. Every `requires` carries a `requireReason` in the character's own terms.
5. **Marked stakes.** Any stock a rule can harm is `role:"vital"` with `bands` - an unmarked stake kills without warning, which is the same as no stake. Every vital reads up-as-good with harm at the floor; a stock whose number climbs toward harm is named for the problem instead of the relief (genesis run 3a89cfab shipped `exposure` and the alarm read exactly backwards - screaming when the character was safest, silent as damage began). Flag those for redesign; repair missing role/bands/icon metadata yourself by re-stating the existing default with `set_stock_default`.
6. **Dead ends.** Stocks with producers and no consumers, or consumers and no producers; entity kinds accumulating far past any use; verbs whose output nothing downstream touches. These are design gaps, not defects - file them for the Tuner (missing sinks, pacing) or the Oracle (missing counterpart verbs). One exemption: anything tagged `latent` is the Seeder's planted mystery - inert on purpose, exempt from every dead-end check, and kept out of the report.
