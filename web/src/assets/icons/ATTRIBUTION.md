# Icon attribution

All icons in this directory are from [game-icons.net](https://game-icons.net),
used under [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/).

This is the **curated bundle**: a small, hand-picked subset kept here (rather
than in `web/public/icons/`) so it eager-loads with the rest of the web
bundle — see `web/src/icons.ts`. It aliases each slug to a short name matching
the tag/stock it draws:

- **Lorc** (https://lorcblog.blogspot.com): wolf-head (wolf), bone-gnawer (carcass),
  tombstone (dead), shiny-apple (food), drop (water), small-fire (fire), pine-tree (forest),
  mining (vein), wheat (farm), anvil (forge), stone-block (stone), metal-bar (metal),
  fishing-hook (fish), campfire, heart-organ (health), cheerful (morale), snowflake-1 (winter)
- **Delapouite** (https://delapouite.com): wood-pile (wood), strawberry (forage),
  wooden-crate (item), stone-pile (quarry), furnace (smelter), crane (buildsite),
  house (structure), person, cargo-crate (stockpile), position-marker (marker),
  thermometer-hot (warmth)
- **sbed**: electric (energy)

Each SVG is the original with the solid background path removed so the white
foreground can be tinted at render time.

## Full set

`web/public/icons/` additionally vendors the **entire** game-icons.net library
(~4100 icons, same CC BY 3.0 license) under its original slugs, generated by
`scripts/vendor-icons.mjs` from the
[`@iconify-json/game-icons`](https://www.npmjs.com/package/@iconify-json/game-icons)
npm package (an official Iconify mirror of
[game-icons/icons](https://github.com/game-icons/icons), not a site scrape).
`iconUrl()` in `web/src/icons.ts` checks this curated bundle first, then falls
back to `/icons/<slug>.svg` — so a GM can point `set_stock_default` /
`register_terrain` at any game-icons.net slug (see the full list at
https://game-icons.net) and it renders with no code change. Re-run the script
after bumping the `@iconify-json/game-icons` version to pick up new/renamed
icons; per-icon authorship lives upstream in the
[game-icons/icons](https://github.com/game-icons/icons) repo.
