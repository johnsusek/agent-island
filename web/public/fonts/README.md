# Fonts

Vendored so the client never fetches type from a CDN at runtime. Both are
licensed under the SIL Open Font License 1.1 (see the `*-OFL.txt` files) and
were converted from the TTFs in the google/fonts repository to WOFF2 without
other changes.

- **Pixelify Sans** (variable, wght 400-700) - body text. Source:
  https://github.com/google/fonts/tree/main/ofl/pixelifysans
- **Silkscreen** (Regular, Bold) - titles, labels and buttons. Its glyphs sit
  on an 8px grid, so it is only ever set at 8px multiples. Source:
  https://github.com/google/fonts/tree/main/ofl/silkscreen
