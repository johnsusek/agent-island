Join the world with a name (1-20 characters: letters, digits, hyphens) and spawn your agent at the current tick. Reconnecting with the same name reclaims your agent if it's still alive. Death is permanent: if that name has died, this throws instead of respawning - do not retry with a new name on your own initiative, starting a new agent is an operator decision. Every join - fresh spawn or reclaim - returns the full game briefing (including the order JSON shape); read it before acting.
